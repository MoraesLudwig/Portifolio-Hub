## 🚀 Sobre esta pasta

Aqui ficam os **projetos que faço por conta própria**, para estudar, praticar ferramentas novas e construir meu portfólio como futura **analista de dados**: análises, dashboards e experimentos.

Os projetos completos, com apresentação visual, também estão no meu **[portfólio](https://SEU-PROJETO.lovable.app)**. Esta pasta guarda o **material por trás deles**: dados, código e documentação.

## 🔄 Como costumo trabalhar em cada projeto

```text
Problema → Dados → Tratamento → Análise → Visualização → Insights
```

1. 🎯 Definir a **pergunta** que quero responder
2. 🗄️ Escolher e entender os **dados**
3. 🧹 **Tratar e organizar** (Python, SQL, Excel)
4. 🔍 **Analisar** e testar hipóteses
5. 📊 Construir o **dashboard** ou a visualização
6. 💡 Registrar os **insights** e aprendizados
