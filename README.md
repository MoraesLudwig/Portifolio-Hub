## 👋 Olá, eu sou a Gabriela!

Sou estudante de **Ciência da Computação no CEUB**, no **8º e último semestre** do curso, e estou construindo minha carreira na área de **análise de dados**. Atualmente atuo em um estágio na área de tecnologia, trabalhando com extração de dados, métricas e dashboards em **Power BI**, em um ambiente com metodologias ágeis.

Gosto de transformar dados em informações claras e úteis para apoiar decisões, e de aprender fazendo: cada projeto deste repositório é um passo nessa jornada. ✨

## 🎯 Objetivos

- 📊 Seguir carreira como **analista de dados**, atuando na coleta, tratamento e visualização de dados
- 🧠 Aprofundar meus conhecimentos em **Python, SQL e Power BI**
- 🗂️ Montar um portfólio sólido, com projetos reais e bem documentados
- 🤝 Colaborar em equipes e aprender com quem já está no mercado

## 📁 Estrutura do repositório

Este repositório é a minha vitrine: além da landing page, vou reunir aqui **trabalhos da faculdade** e **projetos pessoais**, organizados por pastas.

```text
githubpage/
├── index.html                  # Landing page (publicada no GitHub Pages)
├── foto.jpg                    # Foto usada na landing page
├── README.md                   # Este arquivo
│
├── faculdade/                  # 🎓 Trabalhos e projetos, organizados por semestre
│   ├── semestre-1/
│   ├── semestre-2/
│   ├── semestre-3/
│   ├── semestre-4/
│   ├── semestre-5/
│   ├── semestre-6/
│   ├── semestre-7/
│   └── semestre-8/
│       ├── seguranca-digital/  # Segurança Digital
│       └── bootcamp-i/         # Bootcamp I
│
└── projetos-pessoais/          # 🚀 Projetos feitos por conta própria
    └── (uma pasta por projeto, com seu próprio README)
```

| Pasta | O que vai ter lá |
|---|---|
| 🌐 **Raiz** | Arquivos da landing page (`index.html` e `foto.jpg` precisam ficar aqui para o GitHub Pages funcionar) |
| 🎓 **faculdade/** | Trabalhos das disciplinas do curso, com uma pasta para cada um dos 8 semestres. No 8º semestre ficam as disciplinas **Segurança Digital** e **Bootcamp I** |
| 🚀 **projetos-pessoais/** | Análises de dados, dashboards e experimentos que faço para estudar e para o portfólio |

> 💡 **Dica de organização:** cada trabalho ou projeto ganha uma pasta própria, com um `README.md` explicando o objetivo, as ferramentas usadas e como reproduzir.
